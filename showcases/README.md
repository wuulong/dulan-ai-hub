# 🤝 社區創生案例庫 (Showcases)

> **「以物易物嘛通！用 AI 解決在地的真實問題。」**

在這個板塊，我們收集並記錄了都蘭在地居民、店家、小農與樂齡長輩，如何將課堂上學到的 AI 核心技能，實際應用在自己的工作與慢活日常中的真實故事。

這裡不僅是學習成果的展示，更是「都蘭 AI Hub」與社區生活緊密交融的溫度見證。
