# 📄 學員操作手冊與講師維護指引 (Student Operational Manual & Instructor Guide)

本手冊用以規範學員的日常填寫習慣，以及講師如何檢視系統狀態與輔助教學。

> [!NOTE]
> 依據課程陪伴設計調整：本系統不需要額外的助理操作手冊，相關 AI Skill 運作與異常排除由講師直接執行與處理即可。

## 1. 學員（Student）操作規範

- **建立筆記：** 每堂課或每個學習週期，學員需在指定的 Google Drive 資料夾內，複製「學習筆記範本」建立新文件，並將文件名稱命名為固定格式（例如：`[日期]_學員姓名_主題筆記`）。
    
- **內容填寫：** 必須在範本設定的固定標題欄位下填寫，不可刪除或自行更動標題文字，以確保 AI 能精準識別區塊。
    
- **觸發摘要：** 當筆記填寫完成並確認不再更動時，將文件狀態或標籤改為「已完成」（或靜置等待系統夜間自動排程掃描）。

## 2. 講師（Instructor）操作與維護規範

- **歷程檢視：** 講師可定期至 GitHub 儲存庫檢視學員的 Markdown 檔案，透過 Git 的 Commit 紀錄觀察學員的修正歷程與時間軸。
    
- **異常排除：** 若發現學員的筆記未成功同步至 GitHub，講師應檢查：
    
    1. 學員是否誤刪範本欄位。
        
    2. Google Docs 的共用權限是否正確。
        
    3. AI Skill 解析記錄中是否出現 Format Error。
