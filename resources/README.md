## 💡 以物易物折抵申請說明

本共創營支持台東在地的互助文化，學員可申請以物易物折抵部分學費。
*   **折抵標準**：
    *   自產農特產品（如自烘咖啡豆、蜂蜜、優質米）：由現場教練阿鐘評估後進行等值折抵。
    *   勞務支援（如教室清潔、田間拔草、活動拍照）：每小時折抵 NT$ 200 元。
*   **申請方式**：請於第一堂課結束後，向您所在的實體教室陪伴教練登記您的「交換物品」或「勞務支援時段」。
