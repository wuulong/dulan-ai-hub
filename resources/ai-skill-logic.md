# 📄 AI 技能邏輯規範 (AI Skill Logic & Specifications)

本文件詳細定義了 AI Skill 在後台處理資料時的 Prompt 策略、關鍵字提取則與輸出程式邏輯。

## 1. 資料讀取與解析規則

- **區塊定位：** AI 必須利用正則表達式（Regex）或標題文本錨點，將輸入的 Google Docs 內容切分為 `基本資訊`、`課程起點設定`（僅在第一次填寫時存在）、`我今天學到什麼 / 做了什麼`、`我目前的提問` 獨立字串陣列。
    
- **關鍵字提取（Metadata Tagging）：**
    
    - 從【欄位一】（我今天學到什麼 / 做了什麼）中提取出**技術標籤**（如：`Python`, `API_Error`, `Docker`）。
        
    - 從【欄位二】（我目前的提問）中提取出**問題狀態**（如：`待解答`, `已在課堂討論`）。

## 2. 核心 Prompt 邏輯與系統指令

AI Skill 在調用 LLM 時，應內嵌以下系統提示詞：

```plain
# 角色
你是一個精準的教學資料結構化專家。

# 任務
請讀取輸入的學員筆記文字，嚴格按照指定格式提取資訊，並輸出為帶有 Front Matter (YAML) 的標準 Markdown 格式。

# 處理規則
1. 摘要生成：為【學到什麼/做了什麼】與【目前的提問】各產生一段不超過 100 字的精簡摘要。
2. 標籤提取：提取 3-5 個心技術關鍵字，統一轉換為小寫並存入 tags 陣列。
3. 課程期待：若輸入中包含「課程起點設定」的內容（課程目標、痛點與使用現況），需將其結構化保留。
4. 嚴禁幻想：若學員在某個欄位留白，請在 Markdown 對應位置標示「（無填寫）」，不可自行捏造內容。
```

## 3. 輸出 Markdown 格式範例

AI Skill 最終寫入 GitHub 的檔案必須符合以下結構：

```markdown
---
student: "學員姓名"
date: 2026-07-09
topic: "學習主題"
tags: [python, google_drive, api]
status: "待解答"
---

# 課程起點與期待
- **目標與期待**：（帶入學員期待，若為後續上課筆記無此區塊則省略）
- **目前使用 AI 現況**：（帶入學員目前 AI 使用現況）
- **初期的痛點與挑戰**：（帶入學員初期痛點）

# 學習歷程摘要
- **學習/實作摘要**：學員預計串接 Google Drive API 並實作增量更新邏輯。
- **提問摘要**：在處理 API 憑證與權限範圍（Scope）時遇到認證錯誤，需講師解答。

## 我今天學到什麼 / 做了什麼
（此處帶入學員原始填寫內容）

## 我目前的提問
（此處帶入學員原始填寫內容）
```
