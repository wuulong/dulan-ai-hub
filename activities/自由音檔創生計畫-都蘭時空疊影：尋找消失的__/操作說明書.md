# 「尋找都蘭消失了什麼」操作說明書

## 1. 核心設計原則

* **主題目錄化（Topic-based Directory）**：一個主題事件建立一個專屬目錄，作為最小自包含資料單元。目錄名稱即為該主題的唯一識別碼（`topic_id`）。
* **詮釋資料與逐字稿解耦**：
* `meta.yaml`：全中文欄位，人工填寫（整組主題共用一份）。
* `partXX_逐字稿.md`：系統生成（支援單段或多段錄音）。


* **不區分說話者（No Speaker Diarization）**：逐字稿視為整篇連續對話，AI 處理聚焦於「消失的事物、場景、生活樣貌」之提煉，不追究特定發言者。

---

## 2. 資料集目錄結構規範

```text
dataset/
└── {學員編號}/                                # 例：S01
    └── {錄音日期}_{地點}_{主題名稱}/            # 主題目錄（即 topic_id）
        ├── meta.yaml                        # 人工填寫的詮釋資料
        ├── part01.m4a                       # 第 1 段原始音檔
        ├── part01_逐字稿.md                 # 第 1 段逐字稿（系統產出）
        ├── part02.m4a                       # 第 2 段原始音檔（選填/多段時使用）
        └── part02_逐字稿.md                 # 第 2 段逐字稿（選填/多段時使用）

```

* **音檔命名規則**：單段或多段一律命名為 `part01.m4a`、`part02.m4a`...
* **逐字稿命名規則**：對應命名為 `part01_逐字稿.md`、`part02_逐字稿.md`...

## 3. 詮釋資料範本 (`meta.yaml`)

```yaml
# ==========================================
# 尋找都蘭消失了什麼 - 訪談基本資料 (meta.yaml)
# ==========================================

# 1. 採集資訊
學員編號: "S01"
訪談人: "哈爸"
錄音日期: "2026-08-21"

# 2. 故事與時空資訊
故事主題: "都蘭舊糖廠運蔗車與鐵道記憶"
所屬地區: "都蘭"                          # 可填：都蘭 / 台東 / 其他縣市
具體地點: "新東糖廠舊鐵道"                 # 舊路名、老店名或地標
經緯度: [121.2267, 22.8721]               # [選填，不知可留空]
記憶年代: "1960年代"                      # 如：1960年代 / 民國50年代 / 日治時期
關鍵字:
  - "新東糖廠"
  - "五分車"
  - "甘蔗田"

# 3. 受訪者資訊（多位長輩可直接寫在一起）
受訪長輩: "林阿公、陳阿嬤"
年齡層: "70-80多歲"
長輩身分: "都蘭在地長輩"                   # 都蘭在地長輩 / 台東地區居民 / 外地與線上
使用語言: "國台語混用"                     # 國語 / 台語 / 阿美語 / 客語 / 國台語混用

# 4. 公開授權與備註
同意公開: 是                              # 是 / 否
備註: "長輩回憶五分車在轉彎處翻車以及小時候撿甘蔗的情景。"

```

## 4. 系統後端資料處理管線（Pipeline）

```text
[走訪 dataset/*/*]
       │
       ├─▶ 1. 讀取目錄名 ──▶ 取得 topic_id
       │
       ├─▶ 2. 讀取 meta.yaml ──▶ 解析採集人、時空座標、長輩背景
       │
       ├─▶ 3. 依序載入 part*_逐字稿.md ──▶ 拼裝為完整訪談全文 (full_transcript)
       │
       ├─▶ 4. 呼叫 LLM 進行資訊萃取 ──▶ 輸出「故事單元庫 (Story Units)」JSON
       │
       └─▶ 5. 寫入資料庫 (SQLite / JSON DB)
             ├─ 第一層：錄音與主題目錄 (Topics & Metadata)
             ├─ 第二層：萃取出的故事單元庫 (Extracted Story Units)
             └─ 第三層：主題分類彙整 (Categorized Narrative Collections)

```

## 5. AI 故事萃取目標格式（LLM Output Schema）

AI 接收 `meta.yaml` 與 `full_transcript` 後，需輸出結構化 JSON：

```json
{
  "topic_id": "20260821_都蘭_舊糖廠運蔗車",
  "stories": [
    {
      "story_title": "五分車翻車與全村撿甘蔗",
      "vanished_item": "運蔗五分車與舊鐵軌",
      "category": "生活空間", 
      "era": "1960年代",
      "location_tag": "新東糖廠舊鐵道路口",
      "summary": "1960年代新東糖廠每天清晨以五分車運送甘蔗。有一次列車在轉彎處意外翻覆，滿地甘蔗引來全村孩童與居民搶撿。隨著公路運輸興起，鐵道最終於民國60年代末期拆除。",
      "tags": ["五分車", "甘蔗田", "新東糖廠", "童年遊戲"]
    }
  ]
}

```

* `category` 範疇約束：`自然景觀`、`生活空間`、`社會活動`。
