# 🌿 課程紀錄 (Session Records) - 民宿與行銷

本目錄存放主題三「民宿與行銷」每次課程結束後的共創紀錄。這裡記錄了學員們如何利用手機相機拍下都蘭的日常美景與特產，如何利用 AI 辨識生態並撰寫有溫度的行銷故事，以及課堂上的精彩問答與教練觀察。
