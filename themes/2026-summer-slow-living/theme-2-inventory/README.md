# 💰 主題二：進銷存管理

> **「用 AI 理清繁雜的訂單與帳目，讓小店經營更輕鬆自在。」**

本主題針對台東在地店家、民宿主與小農的日常痛點設計。每天出貨、記帳、核對客人的預約與購買資訊，總是耗費大量精力，有時還會漏掉關鍵訊息。

在這裡，我們將利用 AI 的**「表格結構化」**能力，教大家如何把手寫收據、白板照片、或是 LINE 群組裡亂糟糟的留言，一鍵轉換成清晰好讀的電子表格，告別舊式記帳的混亂。
