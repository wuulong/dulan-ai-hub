# 📝 課程紀錄 (Session Records)

本目錄存放主題一「寫書創作」每次課程結束後的共創紀錄。這裡記錄了大家在教室的歡樂時光、實際用語音寫出來的精彩故事、學員問答以及教練的體感回饋。

這是知識庫持續生長與滾動的源泉，後來的學員只要打開這些檔案，就能重溫上課實境！

---

## 📋 課程紀錄模板 (Session Log Template)

當每次課程結束後，教練或助教可以複製以下模板，建立新的 `session-X-log.md` 檔案：

```markdown
# 📝 [第 X 堂] 課程共創紀錄 (YY/MM/DD)

- **上課時間**：19:30 - 21:30
- **課程主題**：[主題名稱]
- **主講人**：哈爸 (線上)
- **現場陪伴教練**：阿鐘、品碩
- **上課教室**：四季八里教室、就醬點教室

---
```
