# 📅 歷屆主題庫 (Themes & Cycles)

在「都蘭 AI 慢活共創營」中，我們不講冷冰冰的理論。每一期，我們都會選擇在地居民與店家最切身相關的**「主題」**，作為學習 AI 核心技能的實踐載體。

上課的過程，也是師生共同將該主題的實踐案例、疑難解答沉澱下來的過程。每一期結束，這裡就會多出一個主題知識板塊。後來的學員不僅能參與當期的新主題，還能隨時翻閱之前累積下來的豐富內容。

## 🔄 知識是如何累積的？
當我們開始上課時，我們會遵循：
1.  **課前導航**：在各主題目錄下建立 `session-X-xxx.md` 計畫（先給地圖與路徑）。
2.  **課堂共創**：在課堂上透過「說話與拍照」解決居民實際問題。
3.  **課後沉澱**：將課堂錄音逐字稿、學員當下成果與 Q&A 整理成 `session-records/session-X-log.md` 存檔。
這樣一來，後來的學員只要打開這些紀錄，就能看到學長姐是怎麼一步步學會並應用的！
